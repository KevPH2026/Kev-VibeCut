二、产品定义

言剪 = 语言驱动剪辑。对仗「剪映」——你动手 vs 你说话。

功能说明优先级
自然语言编辑"把第三段删掉""加渐隐转场""输出 16:9" → AI 自动执行P0
多轨时间线继承 Clypra 完整时间线，Agent 操作 + 手动微调共存P0

三、技术路线

核心判断：Clypra 的 WebGL 渲染引擎是纯 TS，三平台复用同一套代码。

┌─────────────────────────────────────────────────────────┐ │ Agent 层（新增） │ │ 用户输入 → LLM 理解意图 → 生成操作序列 → 执行时间线API │ ├─────────────────────────────────────────────────────────┤ │ Clypra 核心（继承，不改） │ │ WebGL 渲染引擎 · 时间线 · 状态管理 · 撤销/重做 · FFmpeg │ ├─────────────────────────────────────────────────────────┤ │ 平台适配层（补 Web Adapter） │ │ Web 版 ← 需要补 │ 桌面(Tauri) ← 已有 │ 手机(Capacitor) ← 已有 │ └─────────────────────────────────────────────────────────┘
模块现状需要做估时
WebPlatformAdapter接口已定义，无实现文件上传 + IndexedDB 存储1-2 周
帧解码依赖 Rust 原生解码Canvas + video 元素替代1 周
导出依赖 Rust FFmpegFFmpeg.wasm / 云端渲染1-2 周
Agent 层无Tool Use + 时间线 API3-4 周
后端服务无用户系统 + 项目存储 + 模板库2-3 周
总计：8-12 周到 MVP核心引擎不动，只补 adapter + 叠 Agent 层

九、风险与应对

风险概率影响应对
Clypra 原作者弃坑中中Fork 后自主维护，核心引擎已稳定
剪映推出 Agent 功能高高开源差异化 + 先发优势 + 跨境垂直壁垒

对投资人

视频编辑工具的自动驾驶时刻到了。剪映教会了 10 亿人剪视频，但没人教 AI 帮你剪。言剪是第一个用自然语言驱动的开源视频编辑器——底层继承 Clypra 的 S 级渲染引擎，上层叠加 Agent 操作层。开源建社区，托管版赚钱。初始利基是跨境电商卖家——K 已经服务了 15 年的客户群。

对开发者社区

我们 Fork 了 Clypra 并往三个方向推进：Web 版（浏览器里就能用）、Agent 层（自然语言驱动剪辑）、全平台（桌面+手机）。MIT 协议，欢迎贡献。

对跨境客户

你现在的流程：写脚本→拍素材→打开剪映→手动拖拽→调字幕→导出→换尺寸→再导出。用言剪：上传素材→说「帮我剪一条 30 秒的产品展示视频，16:9，加英文字幕，音乐节奏感强一点」→搞定。
