The Real Difference

Not a rewrite. A community upgrade that preserves everything good about Clypra.

Clypra (What we love)

  • Elegant Rust/Tauri + React architecture
  • Professional timeline engine with frame scheduler
  • GPU-accelerated preview pipeline
  • Whisper local transcription
  • FFmpeg-based export with H.264/H.265/ProRes
  • Clean Zustand store architecture
  • TypeScript throughout — 676 test suite

Kev-VibeCut (What we added)

  • Dropped Tauri dependency — runs in any browser
  • 6 platform presets for every social network
  • AI Agent: type commands, get timeline changes
  • 16 Chinese-first templates (also work in EN)
  • Smart subtitle segmentation for all languages
  • Offline BGM library + Pixabay integration
  • One-click watermark with 5 positions
  • Bilingual UI — 中文 / English on the fly

7 Pain Points, Solved

Every change answers a real creator need. Nothing added "just because."

📱

Platform Presets

PAIN: "What resolution for TikTok?"

6 presets one click away. TikTok 9:16, YouTube 16:9, Reels, Shorts, Stories, Cinematic. Auto-detects canvas size. No more guessing.

🤖

AI Agent Editing

PAIN: "I don't want to learn a timeline"

Type "add text Hello World" or "trim to 15s" or "apply template BOOM". The agent places clips on the timeline for you. Natural language → real operations.

💬

Smart Subtitles

PAIN: "Subtitles look robotic"

Intl.Segmenter for word-level CJK segmentation. Whisper auto-transcription with intelligent re-chunking. ~15 chars per line — what human eyes actually read comfortably.

🎨

16 Templates

PAIN: "I'm not a designer"

Pre-built text animation templates: titles, captions, CTAs, outros. Click, apply, done. Works offline. No Studio API required.

🎵

Royalty-Free BGM

PAIN: "Where do I get music?"

6 built-in tracks for offline use. Pixabay API for unlimited royalty-free music. No copyright strikes.

©️

One-Click Watermark

PAIN: "I need my brand on every video"

Set your text or image watermark once. 5 positions, adjustable opacity. Auto-applied on every export frame.

🌐

Pure Web

PAIN: "I don't want to install anything"

Open a URL. That's it. No Tauri, no FFmpeg, no 500MB download. Canvas + MediaRecorder for export. localStorage for persistence.

🔤

Global Fonts

PAIN: "Chinese text looks broken"

Noto Sans SC + LXGW WenKai + Alibaba PuHuiTi. CDN-loaded, ready on first use. Latin fonts kept intact.
